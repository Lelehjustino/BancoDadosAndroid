# Banco de Dados Android

Projeto desenvolvido no Android Studio com Kotlin para praticar a implementação de um banco de dados local utilizando a biblioteca Room.

## Tecnologias utilizadas

* Kotlin
* Android Studio
* Room Database
* SQLite

## Funcionalidades

* Estruturação de uma entidade para armazenar filmes.
* Criação de um banco de dados local.
* Definição de um DAO para operações no banco de dados.

## Objetivo

Aprender os conceitos básicos de banco de dados em aplicações Android, utilizando o Room para facilitar o armazenamento e o gerenciamento de informações.
